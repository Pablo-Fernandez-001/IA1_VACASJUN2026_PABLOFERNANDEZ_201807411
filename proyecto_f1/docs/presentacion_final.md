# Presentación final - Doctor Byte

## Diapositiva 1: Portada
Doctor Byte - Sistema experto para diagnóstico de fallas en computadoras.

## Diapositiva 2: Problema
Usuarios sin conocimientos técnicos tienen dificultad para interpretar síntomas como pantalla negra, reinicios, lentitud o errores de arranque.

## Diapositiva 3: Solución propuesta
Sistema experto que recibe síntomas, consulta reglas en Prolog y genera diagnóstico con recomendaciones.

## Diapositiva 4: Arquitectura
Frontend React, API Gateway FastAPI, Prolog Service, Telegram Service y SQLite.

## Diapositiva 5: Base de conocimiento
Hechos, reglas, listas, variables, recomendaciones y corte en Prolog.

## Diapositiva 6: Funcionalidades
Selección dinámica de síntomas, diagnóstico, recomendaciones, historial y Telegram.

## Diapositiva 7: Demostración
Mostrar caso de fuente, RAM y disco dañado.

## Diapositiva 8: Resultados
Proyecto robusto, modular, funcional y extensible.

## Diapositiva 9: Conclusiones
Se aplicó lógica declarativa e integración de sistemas para resolver un problema real.
