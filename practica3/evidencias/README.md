# Evidencias de SmartInvoice

Las evidencias se separan por flujo para facilitar la evaluacion:

- `ocr/`: imagenes preprocesadas y texto OCR generados automaticamente.
- `rpa/`: capturas PNG, recibos JSON o logs de error generados por Playwright.
- `docker/`: capturas de los tres contenedores saludables.
- `despliegue/`: captura de la URL publica y health check.

Los directorios `ocr/` y `rpa/` reciben archivos al ejecutar el sistema. Las capturas de Docker y nube deben agregarse durante la entrega final porque dependen del equipo y cuenta del estudiante.
